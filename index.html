Live demo

Ask the CV a question.
Watch the page answer.

A voice agent that knows this CV and drives the UI while it talks — a small, production-shaped ElevenLabs Agents integration in a real React app.

Ask “What did Andrii build at Mehrwerk?” and the matching project card lights up on screen. The agent answers from a RAG knowledge base over the CV. The browser never sees an API key: a Next.js route mints a short-lived signed URL, throttled per IP, and the session opens over WebSocket from there.

There is a text mode, so no microphone is needed. The agent, its tools and the knowledge base are code in the repo, pushed with the ElevenLabs CLI, with unit tests on the tool handlers, transcript and throttle.
